1. Target Sentuh ≥ 52px

Seluruh tombol aksi utama, numpad, dan pemilih karkas memiliki tinggi minimum 52px agar tidak meleset saat tangan pedagang basah atau menggunakan sarung plastik.

2. Haptic Synthetic Audio

Setiap ketukan layar menghasilkan audio click sintetis (750 Hz, 25 ms) via Web Audio API sebagai konfirmasi input di tengah kebisingan aktivitas pasar subuh.

3. Zero-Confusion Cash Flow

Memisahkan secara tegas arus uang kas tunai laci (hijau emerald) dengan sisa saldo bon piutang mitra (merah crimson) untuk mencegah defisit modal harian.
